# Contributing

Use `main` for releases and `develop` for integration. Create short-lived branches named `feature/<topic>`, `bugfix/<topic>`, or `devops/<topic>`. Keep commits imperative and focused (for example, `feat: add vendor search`). Open a pull request to `develop`, include the reason and validation commands, and require CI to pass before merge. Protect `main` and avoid committing credentials or `.env` files.
