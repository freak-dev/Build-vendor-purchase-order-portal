Problem and solution

One place to track procurement

Disconnected spreadsheets and email make vendor history, approvals and stock levels difficult to follow.

The portal centralizes procurement records and shows order progress and stock alerts.

  • Vendor and product catalogue
  • Purchase order approval and receipt
  • Inventory adjustment and low-stock alerts
  • Dashboard and CSV reports
Scope: academic MVP for one organization03
Architecture

Application and delivery stack

React + Vite → Nginx → Spring Boot REST API → MySQL

Flyway migrations manage the relational schema. Spring Security enforces role-aware access.

Build and test: Maven, JUnit, Selenium, Playwright

Package and operate: Docker Compose, health checks, Jenkinsfile, Ansible playbook

OpenAPI documentation is available from the backend.

Architecture and ER diagrams: docs/ARCHITECTURE.md04
